PIN berfungsi mengunci karya agar tidak diubah siswa lain saat Anda ingin memperbarui link. Jika Anda lupa PIN, minta guru penguji klik “Reset PIN” pada rekap nilai.

Pertanyaan Sering Diajukan (FAQ)

Bagaimana jika status karya saya dinyatakan “REVISI WAJIB”? +

Buka menu Cek Status Siswa atau Meja Uji untuk membaca catatan evaluasi dari guru penguji. Perbaiki bug atau link yang bermasalah pada aplikasi Anda, lalu kirim ulang perbaikan via Form Kumpul menggunakan PIN yang sama. Status otomatis berubah kembali menjadi MENUNGGU UJI.

Bagaimana cara membagikan file APK / EXE lewat Google Drive agar tidak ditolak? +

Klik kanan file di Google Drive → pilih Bagikan (Share) → pada Akses Umum ubah dari Dibatasi (Restricted) menjadi “Siapa saja yang memiliki link dapat melihat/mengunduh”. Jika akses terkunci, penguji tidak bisa mengunduh file dan status Anda otomatis menjadi REVISI WAJIB.

Bagaimana pembagian bobot penilaian tugas akhir ini? +

Penilaian menggunakan skala 0 sampai 100 dengan 3 kriteria utama:

1. Fungsionalitas & Kesiapan Pakai (40%): Fitur utama berjalan lancar, tidak ada error fatal saat dijalankan.

2. UI/UX & Kerapian Tampilan (30%): Tata letak rapi, responsif saat dibuka di layar HP dan desktop, jelas alur pakainya.

3. Kemanfaatan & Kompleksitas Teknis (30%): Menyelesaikan masalah nyata dan memiliki kedalaman teknis kejuruan TKJ.

Apakah boleh menggunakan bantuan AI, framework, atau template? +

Boleh menggunakan alat bantu dan framework apa pun, asalkan Anda memahami alur kode yang dibuat, mampu mempertanggungjawabkan fungsinya saat ditanya penguji, dan aplikasi terbukti berjalan mulus saat diuji pakai.

Mengapa link localhost atau IP 192.168.x.x otomatis ditolak sistem? +

Alamat localhost dan 192.168.x.x hanya berjalan di komputer pribadi Anda dan tidak bisa dibuka dari internet atau HP penguji. Anda wajib meng-online-kan aplikasi ke platform hosting publik gratis (seperti Vercel, Netlify, atau GitHub Pages) sebelum mengumpulkan.

Kapan batas akhir pengumpulan tugas akhir ini? +

Batas akhir pengumpulan dan pengujian karya adalah 18 Desember 2026. Siswa disarankan mengumpulkan lebih awal agar memiliki waktu untuk memperbaiki karya jika mendapat catatan revisi dari guru.
